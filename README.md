## Features

- Fully bilingual (English ↔ Arabic) with one-click language toggle
- Responsive dark monochrome design
- Smooth scroll animations
- Ready for GitHub Pages

## How to use

1. Replace placeholder projects in the **Work** section with your real videos/photos
2. Update contact email, Instagram, Vimeo, YouTube links
3. Add your portrait/still in the About section
4. Push to a GitHub repository and enable GitHub Pages

## Deploy on GitHub Pages

```bash
# Create a new repo named: yourusername.github.io
# or any repo + enable Pages from main branch / root

git init
git add .
git commit -m "Initial RUYA portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

Then go to **Settings → Pages → Source: Deploy from a branch → main / root**
